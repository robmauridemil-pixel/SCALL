Ajustes

Conexión con el dispositivo y calibración del tanque.

Conexión

Debe empezar con wss:// si el panel se sirve por HTTPS.

Debe coincidir con TOPIC_BASE del sketch. Se suscribe a /telemetria, /estado y publica en /cmd.

Dejar ambos vacíos para un broker público. Con un broker privado, las credenciales se guardan solo en este navegador (localStorage).

Calibración

Distancia desde la cara del sensor hasta el fondo del tanque. Se usa para convertir la distancia medida en porcentaje de nivel.

Simulación

Genera telemetría local con el mismo ciclo de histéresis. No se conecta al broker.

Con el broker público de prueba, cualquier cliente que conozca el tópico puede leer los datos y enviar comandos. Para un montaje real, configurar un broker privado con TLS y credenciales, y un identificador de dispositivo difícil de adivinar.
